# <img src="logo.png" width="48"/> Foton

Foton — программа для снимков экрана под Windows 10/11. Это переработанный порт
[KDE Spectacle](https://invent.kde.org/plasma/spectacle): от исходного приложения
остались захват экрана и редактор, а всё, что нужно было только в Linux и KDE Plasma,
убрано или заменено на возможности Windows.

**Скачать:** готовые `Foton-Setup.exe` и `Foton-portable.7z` — на странице
[Releases](https://github.com/Dr-Livsi/foton-test-repka/releases).

## Установка

- `Foton-Setup.exe` — установщик: Foton появится в меню «Пуск» и в списке программ Windows.
- `Foton-portable.7z` — версия без установки: распакуйте архив в любую папку
  и запустите `bin\foton.exe`. Windows 11 открывает архивы `.7z` сама,
  в Windows 10 понадобится [7-Zip](https://www.7-zip.org/).

Пока у программы нет цифровой подписи, при первом запуске Windows может показать окно
«Windows защитила ваш компьютер» (SmartScreen). Нажмите **Подробнее** → **Выполнить в любом случае**.
Это предупреждение о том, что файл новый и Windows его ещё не знает, а не о вирусе.

## Возможности

### Снимки экрана

- Весь рабочий стол со всеми мониторами, текущий монитор, активное окно, окно под курсором
  (вместе с открытыми меню и всплывающими окнами) и прямоугольная область.
- Окно снимается с рамкой и заголовком или без них, с тенью или без; по желанию на снимок
  попадает указатель мыши.
- Мониторы с разным масштабом (DPI) снимаются в своём исходном разрешении.

### Выделение области

- Экран вокруг выделения затемняется или осветляется, рядом показан размер в пикселях,
  выделение можно двигать и тянуть за края.
- Экранная лупа для точного выделения: всегда, никогда или пока нажата `Shift`.
- По желанию снимок делается сразу, как только отпущена кнопка мыши.
- Выделенную область можно сразу скопировать, сохранить или «Сохранить как…»,
  не открывая редактор.

### Редактор

- Кадрирование, карандаш, маркер, линия, стрелка, прямоугольник, эллипс, текст,
  нумерация, пикселизация и размытие.
- Цвет, толщина, заливка, шрифт и тень; тень для новых фигур включается в настройках.
- Отмена и повтор действий, масштаб снимка.
- Перед закрытием Foton спрашивает, сохранить ли изменения, если снимок отредактирован.

### Текст и коды на снимке

- **Распознавание текста** встроенными средствами Windows 10/11 на любом языке,
  установленном в Windows. Найденные слова подсвечиваются на снимке голубым маркером,
  а рядом показан текст — его можно выделить мышью и скопировать.
- **QR-коды, Data Matrix и штрихкоды** находятся на снимке автоматически: их содержимое
  показывается в окне снимка, ссылки открываются щелчком, текст копируется кнопкой.

### Сохранение

- PNG, JPEG, WebP, TIFF, BMP и другие форматы, качество сжатия настраивается.
- Папка по умолчанию — «Изображения\Снимки экрана», снимок может сохраняться туда сразу.
- Имя файла собирается из блоков: текст, дата, время, название окна, номер по порядку и другие;
  блоки перетаскиваются мышью, формат даты и времени выбирается из примеров.
- В буфер обмена копируется сам снимок или путь к файлу.
- После сохранения появляется уведомление Windows с кнопками «Аннотировать»
  и «Показать в папке».

### Горячие клавиши по умолчанию

| Клавиши          | Действие                                      |
|------------------|-----------------------------------------------|
| `PrtSc`          | Запустить Foton (по умолчанию — выбор области) |
| `Shift+PrtSc`    | Весь рабочий стол                             |
| `Alt+PrtSc`      | Активное окно                                 |
| `Ctrl+PrtSc`     | Прямоугольная область                         |
| `Ctrl+Alt+PrtSc` | Окно под курсором                             |

## Сборка под Windows

### Локально через KDE Craft

Foton использует Qt 6 и KDE Frameworks 6. Удобнее всего собирать его с помощью
[KDE Craft](https://community.kde.org/Craft), который сам соберёт или скачает
все зависимости (Qt, KDE Frameworks, KQuickImageEditor).

1. Установите KDE Craft по [инструкции](https://community.kde.org/Get_Involved/development/Windows)
   (компилятор MSVC, Qt 6).
2. В окне Craft подключите рецепт из этого репозитория и соберите программу:

   ```
   craft --add-blueprint-repository C:\path\to\foton\craft
   craft --src-dir C:\path\to\foton foton
   ```

3. Запуск из окружения Craft: `foton`.
4. Установщик (NSIS) или переносимый архив:

   ```
   craft --src-dir C:\path\to\foton --package foton
   ```

### Сборка вручную

Если зависимости уже установлены (например, в префиксе Craft):

```
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=C:\CraftRoot
cmake --build build
cmake --install build --prefix C:\Foton
```

Полезные опции CMake:

- `BUILD_TESTING=OFF` — не собирать тесты.

На Linux проект тоже собирается (это удобно для разработки и запуска тестов),
но снимать экран умеет только версия для Windows.

## Устройство проекта

- `src/Platforms/ImagePlatformWindows.*` — захват экрана через GDI и DWM.
- `src/GlobalShortcuts.*` — глобальные горячие клавиши (`RegisterHotKey`).
- `src/TrayIcon.*` — значок в системном трее.
- `src/SingleInstance.*` — один экземпляр программы на пользователя.
- `src/Language.*` — выбор языка интерфейса.
- `src/TextRecognition*` и `src/Gui/TextRecognitionWindow.*` — распознавание текста (Windows.Media.Ocr).
- `src/Gui/SettingsDialog/FilenameTemplateEditor.*` — имя файла из блоков.
- `src/WindowsIntegration.*` — «Показать в папке», автозапуск, прогресс на панели задач.
- `src/Geometry.*` — раскладка мониторов с разным масштабом без промежутков.
- `craft/foton/` — рецепт для KDE Craft.
- `tools/prune_package.py` — убирает из пакета для Windows всё, что Foton не использует.
